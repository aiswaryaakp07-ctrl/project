AI Classroom Attention System

Real-time distraction detection using AI vision models to promote smarter and more engaging learning environments.

📚 Project Overview

The AI Classroom Attention System is an educational technology prototype designed to monitor student attention levels using computer vision and machine learning.

By analysing live webcam input through a Teachable Machine model, the system classifies attention into three categories: No Distraction, Medium Distraction, and High Distraction.

This project demonstrates how artificial intelligence can be integrated into classrooms to support data-driven educational insights and improve student engagement.

🎯 Project Objectives

  • Develop a real-time attention monitoring prototype.
  • Apply computer vision techniques in educational settings.
  • Demonstrate practical use of AI for classroom analytics.
  • Provide instant visual feedback through a simple dashboard.
  • Encourage further research into smart learning systems.

⚙️ How It Works

1

Capture

The webcam captures live visual information from the user.

2

Analyse

The trained Teachable Machine model processes the incoming images.

3

Classify

AI predicts the distraction level based on learned patterns.

4

Display

Results are presented instantly through an interactive dashboard.
