AI Classroom Attention System

Real-time distraction detection using AI vision models.

📚 Project Overview

This AI-powered system monitors attention levels through live webcam input. Using a Teachable Machine model, it classifies focus into No Distraction, Medium Distraction, and High Distraction categories.
